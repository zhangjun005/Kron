# Kron logo

当前 logo 已固定为 v1。打开 [`v1.html`](v1.html) 可预览最终版本：四个等大的正方形组成 2×2 标志，第一行是 `K`、`R`，第二行是 `O`、`N`；`N` 所在的象限使用反色处理。

打开 [`index.html`](index.html) 可比较 v1 与两个探索性备选方案。

- [`v1.html`](v1.html)：几何块面版（最终固定）
- [`v2-linear.html`](v2-linear.html)：统一线框版
- [`v3-industrial.html`](v3-industrial.html)：切角工业版

已导出的打包资源：

- [`logo-v1.png`](logo-v1.png)：1024×1024 PNG
- [`logo-v1@2x.png`](logo-v1@2x.png)：2048×2048 PNG
- [`logo-v1.svg`](logo-v1.svg)：矢量版本

如需重新导出 PNG，运行：`python icon/export_logo.py`。
