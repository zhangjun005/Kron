## 分析模板

每个案例文档应包含：

1. **组件清单** - 页面结构拆解
2. **设计语言** - 配色/字体/间距/动效
3. **响应式策略** - 断点与布局变化
4. **可借鉴模式** - ✅ 可直接用 / ⚠️ 需适配 / ❌ 不适用
5. **结论** - 设计定位与参考价值
