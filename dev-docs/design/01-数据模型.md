# Kron 数据模型

> 本文档定义 Kron 所有数据结构的 Rust 类型 + JSON Schema + Markdown Schema。
> 对应需求：dev-docs/requirements.md
> 对应架构：dev-docs/design/00-总览与架构.md § 6

---

## 1. 概述：数据所有权与存储位置

| 数据类型 | 权威源 | Kron 内部镜像 | 说明 |
|---------|--------|-------------|------|
| Task description / title | ✅ KRON/.../tasks.md | ❌ 不存 | 运行时解析 |
| Task tags | ✅ `tags:` 行 | ✅ `tags/tasks.json` | 解析同步 |
| Task state | ❌ 不存 MD | ✅ `states/<vertex>.json` | 5 分钟同步 |
| Task 时间字段 | ❌ 不存 | ✅ 仅内存 | mtime = updated_at |
| Vertex description | ✅ `description.md` | ❌ 不存 | 运行时解析 |
| Vertex 绑定点 | ✅ `_meta.json` | ✅ `vertices.json` 汇总索引 | 守护进程维护 |
| 重要文件内容 | ✅ 双源各一份 | ❌ 不解析 | 纯备份 |
| .kron-context/ | ✅ 仅 KRON/ 下 | ❌ 不存 | 可重新生成 |
| 项目配置 | ❌ 不存 | ✅ `config.json` | CLI / GUI 写入 |

**存储位置速查**：

```
D:\Apps\Kron\data\projects\<项目名>\
├── kron-internal/          ← Kron 内部权威源
│   ├── config.json
│   ├── vertices.json       ← Vertex 汇总索引
│   ├── states/<vertex>.json
│   ├── tags/tasks.json
│   └── important/<relpath> ← 重要文件备份
│
└── KRON/                  ← 项目内（软链接）AI 友好
    ├── README.md
    ├── VERTEX/<name>/
    │   ├── description.md
    │   ├── tasks.md
    │   └── _meta.json
    ├── important/<relpath>
    └── .kron-context/<files>
```

## 2. Project（项目）

### 2.1 Rust 类型

```rust
// kron-core/src/model/project.rs

use chrono::{DateTime, Utc};
use serde::{Deserialize, Serialize};

/// Kron 项目元数据（对应 kron-internal/config.json）
#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct Project {
    /// 项目人类可读名称（默认取目录名）
    pub name: String,

    /// 项目根目录绝对路径
    pub project_path: PathBuf,

    /// Kron 数据目录绝对路径
    pub kron_data_path: PathBuf,

    /// 项目创建时间
    pub created_at: DateTime<Utc>,

    /// 初始化时使用的 Kron 版本
    pub kron_version: String,

    /// 用户配置
    pub settings: ProjectSettings,
}

/// 项目级用户配置（对应 config.json.settings）
#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct ProjectSettings {
    /// 冲突判定阈值（分钟），默认 5
    #[serde(default = "default_conflict_threshold")]
    pub conflict_threshold_minutes: u32,

    /// 冲突自动解决策略：prompt | latest | manual
    #[serde(default = "default_auto_resolve")]
    pub auto_resolve: AutoResolve,

    /// .kron-context/ 刷新间隔（分钟），默认 5
    #[serde(default = "default_context_refresh_minutes")]
    pub context_refresh_minutes: u32,
}

fn default_conflict_threshold() -> u32 { 5 }
fn default_context_refresh_minutes() -> u32 { 5 }
fn default_auto_resolve() -> AutoResolve { AutoResolve::Prompt }

#[derive(Debug, Clone, Copy, PartialEq, Eq, Serialize, Deserialize)]
#[serde(rename_all = "lowercase")]
pub enum AutoResolve {
    /// 提示用户选择
    Prompt,
    /// 自动保留最新
    Latest,
    /// 不自动解决
    Manual,
}

impl Default for ProjectSettings {
    fn default() -> Self {
        Self {
            conflict_threshold_minutes: 5,
            auto_resolve: AutoResolve::Prompt,
            context_refresh_minutes: 5,
        }
    }
}
```

## 3. Vertex（顶点）

### 3.1 Rust 类型

```rust
// kron-core/src/model/vertex.rs

use chrono::{DateTime, Utc};
use serde::{Deserialize, Serialize};

/// Vertex 元数据（对应 KRON/VERTEX/<name>/_meta.json）
#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct VertexMeta {
    /// Vertex 人类可读名称（目录名）
    pub name: String,

    /// 创建时间
    pub created_at: DateTime<Utc>,

    /// 所有绑定点（允许多个）
    pub bind_points: Vec<BindPoint>,
}

/// Vertex 在某个 commit 上的绑定点
#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct BindPoint {
    /// 绑定时的 commit hash（全长）
    pub commit: String,

    /// 绑定时的分支名
    pub branch: String,

    /// 绑定时间
    pub created_at: DateTime<Utc>,
}

impl VertexMeta {
    /// 创建新的 Vertex 元数据
    pub fn new(name: String, commit: String, branch: String) -> Self {
        Self {
            name,
            created_at: Utc::now(),
            bind_points: vec![BindPoint {
                commit,
                branch,
                created_at: Utc::now(),
            }],
        }
    }

    /// 添加新的绑定点
    pub fn add_bind_point(&mut self, commit: String, branch: String) {
        self.bind_points.push(BindPoint {
            commit,
            branch,
            created_at: Utc::now(),
        });
    }
}

/// Vertex 汇总索引项（对应 kron-internal/vertices.json）
#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct VertexSummary {
    pub name: String,
    pub bind_points_count: usize,
    pub latest_bind: String,
    pub latest_bind_branch: String,
    pub latest_bind_at: DateTime<Utc>,
}

impl From<&VertexMeta> for VertexSummary {
    fn from(meta: &VertexMeta) -> Self {
        let latest = meta.bind_points.last().expect("bind_points 不为空");
        Self {
            name: meta.name.clone(),
            bind_points_count: meta.bind_points.len(),
            latest_bind: latest.commit.clone(),
            latest_bind_branch: latest.branch.clone(),
            latest_bind_at: latest.created_at,
        }
    }
}

/// 顶点汇总索引（对应 kron-internal/vertices.json）
#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct VerticesIndex {
    /// 所有 Vertex 的汇总信息
    pub vertices: Vec<VertexSummary>,

    /// 最后更新时间
    pub updated_at: DateTime<Utc>,
}
```

### 3.3 description.md 格式

> description.md 完全自由格式，Kron 不解析、不校验、不存内部镜像。
> 仅在 GUI 中展示和用户/AI 直接编辑。

```markdown
# Vertex: 开发

## 阶段意图

实现用户登录功能模块，包括邮箱、手机号、OAuth。

## 目标

- 抽象 AuthProvider 接口
- 支持三种登录方式
- 完整的 session 管理

## 备注

参考 `legacy-auth/` 项目。
```

**Kron 使用 description.md 的方式**：
- GUI 读取文件内容 → 直接渲染为 Markdown（只读展示或弹出编辑器）
- 搜索时不解析内容（description.md 是自由文本）
- 修改不触发任何逻辑（仅文件 mtime 变化用于"最近更新"显示）

## 4. Task（任务）

### 4.1 Rust 类型

```rust
// kron-core/src/model/task.rs

use chrono::{DateTime, Utc};
use serde::{Deserialize, Serialize};
use std::collections::HashSet;

/// Task 状态（仅存在于 Kron 内部，不在 MD 中）
#[derive(Debug, Clone, Copy, PartialEq, Eq, Serialize, Deserialize, Default)]
#[serde(rename_all = "lowercase")]
pub enum TaskState {
    /// 待处理
    #[default]
    Todo,
    /// 进行中
    InProgress,
    /// 已完成
    Done,
}

impl std::fmt::Display for TaskState {
    fn fmt(&self, f: &mut std::fmt::Formatter<'_>) -> std::fmt::Result {
        match self {
            TaskState::Todo => write!(f, "todo"),
            TaskState::InProgress => write!(f, "in_progress"),
            TaskState::Done => write!(f, "done"),
        }
    }
}

impl std::str::FromStr for TaskState {
    type Err = String;
    fn from_str(s: &str) -> Result<Self, Self::Err> {
        match s.to_lowercase().as_str() {
            "todo" => Ok(TaskState::Todo),
            "in_progress" | "inprogress" => Ok(TaskState::InProgress),
            "done" => Ok(TaskState::Done),
            _ => Err(format!("无效状态: {}", s)),
        }
    }
}

/// Task 标签（从 MD tags: 行解析）
#[derive(Debug, Clone, Serialize, Deserialize, Default)]
pub struct TaskTags {
    pub tags: HashSet<String>,
}

impl TaskTags {
    pub fn new() -> Self {
        Self { tags: HashSet::new() }
    }

    pub fn from_line(line: &str) -> Self {
        // 从 "tags: #后端 #认证 #feature" 解析
        let prefix = "tags:";
        if !line.starts_with(prefix) {
            return Self::new();
        }
        let rest = &line[prefix.len()..];
        let tags: HashSet<String> = rest
            .split_whitespace()
            .filter(|t| t.starts_with('#'))
            .map(|t| t.to_string())
            .collect();
        Self { tags }
    }

    pub fn to_line(&self) -> String {
        if self.tags.is_empty() {
            String::new()
        } else {
            let sorted: Vec<_> = self.tags.iter().sorted().collect();
            format!("tags: {}", sorted.join(" "))
        }
    }
}

/// Task 核心信息（从 tasks.md 解析得到，运行时使用，不持久化）
#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct Task {
    /// Task ID，如 "task_001"
    pub id: TaskId,

    /// Task 标题（## [...] 后的文字）
    pub title: String,

    /// Task 所属 Vertex 名
    pub vertex: String,

    /// 描述文本（解析 ### 背景/目标/实现方案/备注 后的原始文本）
    pub description: TaskDescription,

    /// 标签（从 tags: 行解析）
    pub tags: TaskTags,

    /// 所在 tasks.md 的绝对路径
    pub source_file: PathBuf,

    /// 在文件中的起始行号（用于错误定位）
    pub start_line: usize,
}

/// Task ID（格式：task_\d+）
#[derive(Debug, Clone, PartialEq, Eq, Hash, Serialize, Deserialize)]
pub struct TaskId(pub String);

impl TaskId {
    /// 从字符串解析 task ID
    pub fn parse(s: &str) -> Result<Self, ParseTaskIdError> {
        let re = Regex::new(r"^task_(\d+)$").unwrap();
        if let Some(caps) = re.captures(s) {
            let num = caps.get(1).unwrap().as_str();
            if num.parse::<u32>().is_ok() {
                return Ok(Self(s.to_string()));
            }
        }
        Err(ParseTaskIdError(s.to_string()))
    }

    pub fn as_str(&self) -> &str {
        &self.0
    }
}

#[derive(Debug, Clone, PartialEq, Eq)]
pub struct ParseTaskIdError(pub String);

impl std::fmt::Display for ParseTaskIdError {
    fn fmt(&self, f: &mut std::fmt::Formatter<'_>) -> std::fmt::Result {
        write!(f, "无效的 task ID 格式: {}，期望 task_数字", self.0)
    }
}

impl std::error::Error for ParseTaskIdError {}

/// Task 描述文本（解析后的结构化文本）
#[derive(Debug, Clone, Default, Serialize, Deserialize)]
pub struct TaskDescription {
    /// 背景
    pub background: Option<String>,
    /// 目标
    pub goal: Option<String>,
    /// 实现方案
    pub plan: Option<String>,
    /// 备注
    pub note: Option<String>,
    /// 自由文本（不属于以上四个二级标题的所有内容）
    pub free_text: String,
}

impl TaskDescription {
    /// 渲染为纯文本（用于展示和 AI 读取）
    pub fn to_text(&self) -> String {
        let mut parts = Vec::new();
        if let Some(bg) = &self.background {
            parts.push(format!("### 背景\n{}", bg));
        }
        if let Some(goal) = &self.goal {
            parts.push(format!("### 目标\n{}", goal));
        }
        if let Some(plan) = &self.plan {
            parts.push(format!("### 实现方案\n{}", plan));
        }
        if let Some(note) = &self.note {
            parts.push(format!("### 备注\n{}", note));
        }
        if !self.free_text.is_empty() {
            parts.push(self.free_text.clone());
        }
        parts.join("\n\n")
    }
}

/// Task 运行时状态元数据（GUI 用，存于 states/<vertex>.json）
#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct TaskStateEntry {
    /// Task ID
    pub id: String,
    /// 当前状态
    pub state: TaskState,
    /// 进入当前状态的时间（用于统计）
    pub state_changed_at: DateTime<Utc>,
    /// 状态历史（用于 back 命令回退）
    pub history: Vec<StateTransition>,
}

/// 状态转换记录
#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct StateTransition {
    pub from: TaskState,
    pub to: TaskState,
    pub changed_at: DateTime<Utc>,
}

/// Vertex 级别的 task 状态文件（对应 states/<vertex>.json）
#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct VertexTaskStates {
    pub vertex: String,
    /// task_id → 状态信息
    pub tasks: HashMap<String, TaskStateEntry>,
    /// 最后更新时间
    pub updated_at: DateTime<Utc>,
}

impl VertexTaskStates {
    pub fn new(vertex: String) -> Self {
        Self {
            vertex,
            tasks: HashMap::new(),
            updated_at: Utc::now(),
        }
    }

    /// 更新单个 task 的状态
    pub fn set_state(&mut self, task_id: &str, new_state: TaskState) {
        let now = Utc::now();
        let entry = self.tasks.entry(task_id.to_string()).or_insert_with(|| {
            TaskStateEntry {
                id: task_id.to_string(),
                state: TaskState::Todo,
                state_changed_at: now,
                history: Vec::new(),
            }
        });
        if entry.state != new_state {
            entry.history.push(StateTransition {
                from: entry.state,
                to: new_state,
                changed_at: now,
            });
            entry.state = new_state;
            entry.state_changed_at = now;
        }
        self.updated_at = now;
    }

    /// 获取上一状态（用于 back 命令）
    pub fn get_previous_state(&self, task_id: &str) -> Option<TaskState> {
        self.tasks.get(task_id)?
            .history
            .last()
            .map(|t| t.from)
    }
}

/// 全局 tags 索引（对应 kron-internal/tags/tasks.json）
#[derive(Debug, Clone, Serialize, Deserialize, Default)]
pub struct GlobalTagsIndex {
    /// task_id → [tags]
    pub tags: HashMap<String, Vec<String>>,
    pub updated_at: DateTime<Utc>,
}

impl GlobalTagsIndex {
    pub fn new() -> Self {
        Self {
            tags: HashMap::new(),
            updated_at: Utc::now(),
        }
    }

    pub fn set_tags(&mut self, task_id: &str, tags: Vec<String>) {
        self.tags.insert(task_id.to_string(), tags);
        self.updated_at = Utc::now();
    }

    pub fn remove(&mut self, task_id: &str) {
        self.tags.remove(task_id);
        self.updated_at = Utc::now();
    }
}
```

## 5. Task Markdown 格式规范（完整版）

> 这是需求文档 § 2.3.4 的精化版本，作为 MD 解析器的实现规范。

### 5.1 格式规则

| 元素 | 格式 | 示例 |
|------|------|------|
| 文件路径 | `KRON/VERTEX/<name>/tasks.md` | |
| Task 标题 | `## [task_XXX] 标题` | `## [task_001] 实现登录功能` |
| 二级标题 | `### 背景` / `### 目标` / `### 实现方案` / `### 备注` | `### 背景` |
| Tags 行 | `tags: #tag1 #tag2`（单行，必须在 task 块内） | `tags: #后端 #认证` |
| Task 分隔 | `---`（块之间，可选） | `---` |
| 注释元数据 | `<!-- kron:task_meta ... -->`（可选，用于时间戳等） | |

### 5.2 完整示例

```markdown
认证模块依赖基础数据表。

### 目标

用户表、会话表、权限表。

tags: #后端 #数据库

---

## [task_003] 性能优化

### 背景

当前接口响应时间超过 200ms。

tags: #性能 #优化
```

### 5.3 解析规则（MD 解析器实现规范）

**硬约束（校验失败 = 格式错误）**：
1. `## [task_XXX]` 中 `XXX` 必须匹配 `^task_(\d+)$`（可前导零，如 `task_001`）
2. 同一 `tasks.md` 内 ID 必须唯一（重复 ID 报错）
3. `tags:` 行必须在 task 块的**最后一个非空行**（或紧接着 `---`）
4. `tags:` 行前导必须是 `tags:`（大小写敏感）

**软约束（警告但不阻断）**：
1. task 应至少有 `### 背景` 或 `### 目标`（否则给出格式建议警告）
2. `tags:` 行应至少有 1 个 tag（空 `tags:` 行警告）
3. task 块之间应有 `---` 分隔（缺少警告但不断）

**解析算法**：
```
1. 读取文件 → 按行分割
2. 扫描所有 "## [task_XXX]" 行 → 记录行号和 ID
3. 对每个 task：
   a. 从 "## [task_XXX]" 行到下一个 "## [task_YYY]" 或文件末尾为 task 块
   b. 第一行为标题（提取 ID 和 title）
   c. 扫描块内所有 "### XXX" 二级标题 → 归入 description
   d. 扫描块内最后一行（允许空行）：匹配 "tags: #..." → 解析 tags
   e. 检查块内是否有 <!-- kron:task_meta --> → 提取元数据
4. 校验：ID 唯一性、tags 行位置、ID 格式
5. 返回 Vec<Task> 或 Vec<ParseError>
```

### 5.4 渲染回写（tasks.md → 保持原格式）

**原则**：Kron 写回 MD 只在以下情况发生：
- `kron init` 初始化时创建空 `tasks.md`
- `kron task fix` 自动修复格式问题

**正常情况下 Kron 不改写 tasks.md**（用户/AI 直接编辑，Kron 只解析）。

## 6. Important Files（重要文件）

### 6.1 Rust 类型

```rust
// kron-core/src/model/important.rs

use chrono::{DateTime, Utc};
use serde::{Deserialize, Serialize};

/// 重要文件元数据（存于 kron-internal/important/_meta.json）
#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct ImportantFilesIndex {
    /// 相对于项目根的路径 → 文件信息
    pub files: HashMap<String, ImportantFileMeta>,

    /// 最后更新时间
    pub updated_at: DateTime<Utc>,
}

#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct ImportantFileMeta {
    /// 相对于项目根的原始路径
    pub relative_path: String,

    /// 文件大小（字节）
    pub size: u64,

    /// 添加到 important 的时间
    pub added_at: DateTime<Utc>,

    /// 最后修改时间（同步时更新）
    pub updated_at: DateTime<Utc>,

    /// MD5 校验和（用于大文件增量同步）
    pub content_hash: String,

    /// 双源同步状态
    pub sync_state: SyncState,
}

#[derive(Debug, Clone, Copy, PartialEq, Eq, Serialize, Deserialize)]
#[serde(rename_all = "lowercase")]
pub enum SyncState {
    /// 双源都已同步
    Synced,
    /// 仅 Kron 内部存在
    InternalOnly,
    /// 仅项目内存在
    ProjectOnly,
    /// 冲突（双源都有且内容不同）
    Conflict,
    /// 正在同步
    Syncing,
}

impl ImportantFilesIndex {
    pub fn new() -> Self {
        Self {
            files: HashMap::new(),
            updated_at: Utc::now(),
        }
    }

    pub fn add_file(&mut self, path: String, size: u64, hash: String) {
        self.files.insert(path.clone(), ImportantFileMeta {
            relative_path: path,
            size,
            added_at: Utc::now(),
            updated_at: Utc::now(),
            content_hash: hash,
            sync_state: SyncState::Synced,
        });
        self.updated_at = Utc::now();
    }

    pub fn remove_file(&mut self, path: &str) {
        self.files.remove(path);
        self.updated_at = Utc::now();
    }
}
```

## 8. 同步与冲突

### 8.1 Rust 类型

```rust
// kron-core/src/model/sync.rs

use chrono::{DateTime, Utc};
use serde::{Deserialize, Serialize};
use std::path::PathBuf;

/// 同步方向判断结果
#[derive(Debug, Clone, Copy, PartialEq, Eq, Serialize, Deserialize)]
pub enum SyncDirection {
    /// 项目内 → Kron 内部
    ProjectToInternal,
    /// Kron 内部 → 项目内
    InternalToProject,
    /// 冲突（需用户决策）
    Conflict,
    /// 无需同步（双方相同）
    AlreadySynced,
    /// 源不存在，无需操作
    SourceNotFound,
}

/// 双源文件对
#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct FilePair {
    /// 项目内文件路径
    pub project_path: PathBuf,

    /// Kron 内部文件路径
    pub internal_path: PathBuf,

    /// 项目内文件修改时间
    pub project_mtime: DateTime<Utc>,

    /// Kron 内部文件修改时间
    pub internal_mtime: DateTime<Utc>,

    /// 同步状态
    pub sync_state: SyncState,
}

/// 冲突记录（用于备份和用户决策）
#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct ConflictRecord {
    /// 冲突 ID（时间戳 + 文件名 hash）
    pub id: String,

    /// 文件相对路径
    pub relative_path: String,

    /// 冲突发现时间
    pub detected_at: DateTime<Utc>,

    /// 项目内版本路径
    pub project_version: PathBuf,

    /// Kron 内部版本路径
    pub internal_version: PathBuf,

    /// 项目内版本 mtime
    pub project_mtime: DateTime<Utc>,

    /// Kron 内部版本 mtime
    pub internal_mtime: DateTime<Utc>,

    /// 当前状态
    pub status: ConflictStatus,
}

#[derive(Debug, Clone, Copy, PartialEq, Eq, Serialize, Deserialize)]
#[serde(rename_all = "lowercase")]
pub enum ConflictStatus {
    /// 等待用户决策
    Pending,
    /// 已解决
    Resolved,
    /// 用户忽略
    Ignored,
}

impl ConflictRecord {
    pub fn new(
        relative_path: String,
        project_path: PathBuf,
        internal_path: PathBuf,
        project_mtime: DateTime<Utc>,
        internal_mtime: DateTime<Utc>,
    ) -> Self {
        let id = format!(
            "{}_{}",
            Utc::now().format("%Y%m%d%H%M%S"),
            simple_hash(&relative_path)
        );
        Self {
            id,
            relative_path,
            detected_at: Utc::now(),
            project_version: project_path,
            internal_version: internal_path,
            project_mtime,
            internal_mtime,
            status: ConflictStatus::Pending,
        }
    }
}

/// 复原操作记录
#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct RestoreRecord {
    pub id: String,
    pub triggered_by: RestoreTrigger,
    pub started_at: DateTime<Utc>,
    pub finished_at: Option<DateTime<Utc>>,
    pub files_restored: Vec<String>,
    pub status: RestoreStatus,
}

#[derive(Debug, Clone, Copy, PartialEq, Eq, Serialize, Deserialize)]
#[serde(rename_all = "lowercase")]
pub enum RestoreTrigger {
    /// 守护进程自动检测
    DaemonAuto,
    /// 用户手动触发
    Manual,
    /// Git checkout/merge/pull 后
    GitOperation,
}

#[derive(Debug, Clone, Copy, PartialEq, Eq, Serialize, Deserialize)]
#[serde(rename_all = "lowercase")]
pub enum RestoreStatus {
    Running,
    Success,
    PartialSuccess,
    Failed,
}
```
